## 🚀 Live Demo & Deployment to Vercel

You can deploy this portfolio to Vercel in **less than 2 minutes** using either the Vercel Dashboard (GitHub) or the Vercel CLI:

### Option 1: Deploy via Vercel Dashboard (Recommended)

1. Push this folder to a new repository on your GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Aindla Steven Portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/aindla-steven-portfolio.git
   git push -u origin main
   ```
2. Log in to [Vercel](https://vercel.com).
3. Click **"Add New..."** -> **"Project"**.
4. Import your newly created `aindla-steven-portfolio` repository.
5. Vercel automatically detects the static HTML project (`vercel.json`). Click **"Deploy"**.
6. Done! Your portfolio is live with a free custom SSL domain (`https://aindla-steven-portfolio.vercel.app`).

---

### Option 2: Deploy directly with Vercel CLI

1. Open PowerShell or Command Prompt inside the project directory:
   ```bash
   cd "C:\Users\mamin\.gemini\antigravity\scratch\aindla-steven-portfolio"
   ```
2. Run Vercel deploy:
   ```bash
   npx vercel
   ```
3. Follow the CLI prompts to link to your Vercel account and deploy immediately to production:
   ```bash
   npx vercel --prod
   ```
